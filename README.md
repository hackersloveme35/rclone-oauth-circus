## 🔔 Introducing our flagship product: Ring for Approval™

The website includes a button that rings a metaphorical bell and issues cheerful administrative updates.

- A remarkably official-looking status message.
- A paperwork-completion indicator with an ambitious denominator: **∞**.
- Several bells exercising their right to free movement.
- A portrait of Sundar Pichai overseeing proceedings in a purely decorative, absolutely non-official capacity.

**Regulatory note:** Pressing the bell does not contact Google, submit an OAuth application, authorize rclone, transfer files, or summon an executive. It changes text in your browser. We consider this a refreshingly straightforward API.

## 🧠 What this project *actually* does

Behind the ceremonial atmosphere is an ordinary, personal rclone setup:

1. The owner authorizes their Google account through Google's OAuth flow.
2. The owner chooses Linux workstation/server files and runs explicit rclone commands.
3. Rclone transfers or verifies those files against Google Drive.

**Important:** This website is static information and parody, **not** a backup service, OAuth callback handler, or credential collector. It never handles Google access tokens, passwords, or Drive files.

The configured OAuth scope may give rclone **broad Google Drive access**, including the ability to read, modify, and delete files. Actual operations depend on commands run by the owner. See the [privacy policy](privacy.html).

## 🌍 Hosting, because a folder needed a homepage

This project is intended for **GitHub Pages**. The requested infrastructure does not include a public VPS, a complicated Kubernetes deployment, or a ceremonial committee meeting.

To publish:

1. Open **Repository Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then **Save**.
4. Verify the published links over HTTPS before entering them in Google OAuth Branding.

| Google Branding field | Proposed URL |
|---|---|
| Application home | https://hackersloveme35.github.io/rclone-oauth-circus/ |
| Privacy policy | https://hackersloveme35.github.io/rclone-oauth-circus/privacy.html |
| Terms of service | https://hackersloveme35.github.io/rclone-oauth-circus/terms.html |

Publishing this website does **not** itself verify an OAuth app or override Google Advanced Protection or other security controls.
