# RCLONE — The Great OAuth Approval Circus 🔔

A fan-made parody site for a **personal, owner-operated rclone Google Drive OAuth integration**. It documents its actual purpose, data handling, and user terms while making a little fun of lengthy OAuth configuration.

**Live site (after GitHub Pages is enabled):** https://hackersloveme35.github.io/rclone-oauth-circus/

## Enable GitHub Pages
Open **Settings → Pages → Build and deployment → Deploy from a branch**, select **main** and **/(root)**, then save. Verify the public homepage, privacy and terms pages over HTTPS before using these links in Google Cloud OAuth Branding.

- Home: `https://hackersloveme35.github.io/rclone-oauth-circus/`
- Privacy: `https://hackersloveme35.github.io/rclone-oauth-circus/privacy.html`
- Terms: `https://hackersloveme35.github.io/rclone-oauth-circus/terms.html`

The homepage contains embedded CSS/JS and a Creative Commons Wikimedia image; its bell button is a local joke, **not** a real Google authorization request. The privacy and terms pages use `styles.css`. The website has no OAuth redirect handler and never processes Google access tokens or backups.
