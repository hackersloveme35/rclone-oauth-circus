What this app really does.

This is a personal, owner-operated Google Drive OAuth connection for rclone, a file-transfer utility. It is not a public SaaS product or login service.

01 / AUTHORIZE

Owner-controlled access

The Google account owner authorizes the rclone client through Google's OAuth authentication flow.

02 / BACK UP

Select and copy

The owner selects local Linux workstation and server files and explicitly runs rclone commands to transfer them.

03 / VERIFY

Restore when needed

The owner can list, verify, download or restore files. This static website never accesses Google Drive itself.

⚠️

Actual Google permission disclosure

The integration may request the full Google Drive scope. That gives rclone the technical ability to view and manage Google Drive files, including modifying and deleting files—not just the chosen backup folder. The owner controls the actual commands. This static website never handles passwords, Drive files or OAuth tokens. Read the privacy policy.
