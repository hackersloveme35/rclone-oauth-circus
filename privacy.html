Privacy policy.

This policy describes a private, owner-operated Google Drive connection that uses the open-source rclone utility for personal backups. It also covers this informational website.

1. Who operates it

This is a personal integration, not a public-facing backup provider. The operator controls the participating workstations, Google account authorization, backup instructions, and stored credentials. For inquiries, use the support contact presented on the app's Google OAuth consent screen.

2. Google user data accessed

The integration may request the Google Drive full-access OAuth scope (https://www.googleapis.com/auth/drive). This grants the authorized client the technical ability to view, download, upload, modify, and delete files in the permitted Google Drive account, excluding the separate Application Data folder. The operator chooses which rclone commands and file paths are used. It is not limited technically to one backup folder by the OAuth permission itself.

3. Purpose and use

The authorized integration accesses Google Drive data only to perform the owner's chosen backup, listing, verification, restoration, or file-management commands. It may read file names, identifiers, sizes, timestamps, content and other metadata needed for those operations. It does not automatically upload data simply because this website is viewed.

4. Storage and transfers

Rclone transfers files between systems under the operator's control and Google Drive using Google's APIs. OAuth credentials and local configuration are maintained on the operator's own machine(s), not collected by this website. Backup files stored in Google Drive are subject to the Google account's settings and Google's service practices. No claim is made here that all backup content is end-to-end encrypted.

5. Sharing and sale

The operator does not sell Google user data or provide it to advertisers. This personal integration does not intentionally disclose Google user data to independent third parties, apart from transfers to Google Drive that the owner authorizes. Google's processing and the operator's infrastructure providers may be involved in delivering their respective services.

6. Retention and deletion

The operator controls when to delete local copies, Google Drive backup files, and OAuth credentials. Removing the OAuth app's access from Google Account settings can revoke future access; previously uploaded Drive files remain in the account until separately deleted. Any application logs or temporary files depend on the executed rclone commands and local system configuration.

7. Website visitors

This informational website contains no analytics scripts, marketing trackers, account forms, or cookies set by its own HTML and CSS. Once hosted, the web server or hosting provider may process ordinary connection details (such as an IP address, user agent, and time of access) for service delivery and security; logging and retention depend on the hosting configuration.

8. Changes and contact

The operator may update this policy to reflect changes to the private integration. For questions or access concerns, use the OAuth application's designated Google user-support contact. This site is independent of Google and the official rclone project.
